Apps Script Samples

Small, working Google Apps Script samples. No hardcoded IDs or email addresses — every sample is configured through Script Properties, and the destructive ones dry-run first.

This site is generated from the samples themselves: run npm run build:site after editing a sample, and the catalogue, code view, and scopes below stay in sync.

Use a sample: copy its Code.gs and appsscript.json into a script project, set its Script Properties, run it once, and check the log before enabling any trigger. Live Google runs are the owner's step — nothing here runs against your account from this page.
